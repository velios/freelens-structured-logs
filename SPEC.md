# freelens-structured-logs — спецификация v1

Личное локальное расширение FreeLens для чтения логов одного пода в формате Logstash JSON. Решения согласованы 2026-10-20. Факты об API собраны по исходному коду FreeLens.

## Окружение

- FreeLens 1.10.3 (`/Applications/Freelens.app`), папка расширений `~/.freelens/extensions` (пустая).
- Шаблон: `freelensapp/freelens-example-extension`, тег `v1.10.2` (electron-vite, TS, React 17, mobx 6, pnpm). Ветка `main` шаблона относится к FreeLens 2.x и не подходит.
- `@freelensapp/extensions@1.10.3`, `engines.freelens: "^1.10.0"`.
- Hot-reload нет: после каждой пересборки FreeLens перезапускается.

## Формат логов

Используется только Logstash JSON, одна запись на строку:

```json
{"@timestamp":"2026-10-20T18:42:09.879376854Z","@version":"1","message":"Starting AppKt v1.0.0 using Java 21.0.12.1 with PID 1 (/app.jar started by root in /)","logger_name":"com.example.app.AppKt","thread_name":"main","level":"INFO","level_value":20000,"tags":["COMMONS-LOGGING"]}
```

- Читаются поля `@timestamp`, `level`, `message`, `logger_name`, `stack_trace`.
- Уровни: TRACE, DEBUG, INFO, WARN, ERROR.
- Строка, которая не разобралась как JSON или в которой нет `message`, показывается как есть, без форматирования и без склейки с соседними строками.
- `@timestamp` содержит наносекунды, при разборе их нужно учесть.
- Go `log/slog` JSON тоже разбирается: `msg` читается, если нет `message`, а `time` — если нет `@timestamp`.
- В Go-логах строковое поле `error` показывается в строке после сообщения: `msg: error`.

## Точка входа и вкладка

- `kubeObjectMenuItems` у Pod добавляет пункт «Structured logs». Он открывает вкладку в нижней панели (dock), как у встроенных логов. Решение принято 2026-10-20 вместо страницы кластера.
- Своего вида вкладки у расширений нет (freelensapp/freelens#731). Поэтому пункт создаёт стандартную вкладку логов пода (`logTabStore.createPodTab`). Наш просмотрщик монтируется в элемент `[data-testid="dock-tab-content-for-<id>"]` поверх скрытого встроенного. Высоту, развёртывание, сворачивание, закрытие и несколько вкладок даёт сама панель.
- Вкладка помечается `{ }` перед заголовком. Пока вкладка открыта, просмотрщик живёт и при её скрытии (переключение, сворачивание), поток и буфер сохраняются. Закрытие вкладки прерывает поток.
- Связь «вкладка → под» хранится в `tabs-<clusterId>.json` в папке расширения (`getExtensionFileFolder`). После перезапуска FreeLens вкладки восстанавливаются с нашим просмотрщиком.
- Встроенной вкладке выставляется `showPrevious: true`. Иначе скрытый встроенный просмотрщик раз в 10 с дописывает новые строки в свой буфер без лимита. В режиме previous он один раз загружает прошлый запуск, а если его нет, получает ошибку и перестаёт опрашивать. Запросы только на чтение.
- Решение опирается на внутреннюю разметку панели (`.Dock`, `.tab-content`, `data-testid`, `#tab-<id>`), а не на API.
- Шапка: `ns/pod`, выбор контейнера (init-контейнеры тоже), переключатель Previous. С v2 кнопки «← Pod» нет.
- По умолчанию открывается первый контейнер. При смене контейнера буфер очищается и поток перезапускается.

## Поток логов

- Основной путь — стриминг `follow=true`, `timestamps=true`, при открытии `tailLines=1000`. Запрос: `new Renderer.K8sApi.KubeJsonApi({serverAddress: "https://127.0.0.1:" + location.port, apiBase: "/api-kube"}, {headers: {Host: location.host}}).getResponse(url, {query}, {signal})`. `response.body` — Node-поток, его читают построчно. Этот путь выведен из кода и не проверен, проверка — первый шаг реализации (spike).
- Если стриминг не заработает, вместо него опрос раз в 2 с с `sinceTime` (как во встроенном просмотрщике, `dock/logs/store.ts`). `sinceTime` имеет секундную точность, поэтому нужна дедупликация.
- При обрыве потока (рестарт контейнера, таймаут) — переподключение с `sinceTime` по последней метке kubelet, уже виденные строки пропускаются.
- Поток прерывается через AbortController при закрытии вкладки, кластера или окна, при смене контейнера или режима.
- Previous: логи прошлого запуска загружаются один раз, без `follow`. Поток не открывается, автопрокрутки нет, сверху плашка «previous container». Если прошлого запуска нет, показывается сообщение API, а не пустой экран.

## Строка лога

- Время: `@timestamp`, при его отсутствии время kubelet. Показывается локальное время `HH:mm:ss.SSS`, полная дата во всплывающей подсказке.
- Цветной `level`: ERROR красный, WARN жёлтый, INFO нейтральный или синий, DEBUG и TRACE серые.
- Короткое имя логгера (`AppKt` из `com.example.app.AppKt`) приглушённым цветом, полное имя во всплывающей подсказке.
- `message` с переносом строк, перенос всегда включён.
- Моноширинный шрифт. Цвета берутся из CSS-переменных темы FreeLens, светлой и тёмной.

## Раскрытие

- По клику на строку показывается отформатированный JSON целиком с кнопкой Copy. Раскрывать можно несколько строк одновременно.
- `stack_trace` выводится отдельным моноширинным блоком с переносами. Фреймы `java.*` и `clojure.lang.*` приглушены.

## Поиск и фильтры

- Поиск идёт по всей исходной строке: подстрока без учёта регистра, флажок `.*` включает regex. Несовпадающие строки скрываются. С v4 поиск устроен иначе, см. «v4: поиск».
- Чипы уровней TRACE / DEBUG / INFO / WARN / ERROR, по умолчанию включены все. Строки без уровня видны всегда.

## Буфер и прокрутка

- В памяти до 10 000 записей, старые выбрасываются первыми. Начальный объём и лимит — константы.
- Если прокрутить вверх, автопрокрутка встаёт на паузу. Поток при этом продолжает идти, а кнопка «↓ N новых» возвращает вниз и снова включает автопрокрутку.
- Видимая строка не должна прыгать, когда сверху выбрасываются старые записи (`overflow-anchor`).
- Рендер без зависимостей: обычный список и CSS `content-visibility: auto`. Виртуализацию (`@tanstack/react-virtual`) добавлять только после вопроса пользователю, если реальный поток заметно тормозит.

## Не входит в v1

Экспорт в файл, сохранение фильтров между сессиями, подсветка синтаксиса внутри `message`, настройки в UI, другие форматы логов.

## Проверка

- Юнит-тесты только на чистые функции: разбор Logstash, наносекунды в `@timestamp`, короткое имя логгера, строки без JSON; с v2 — метка пода, выбор подов, слияние по времени. Примеры фиксированные.
- Живая проверка — только чтение логов одного пода в рабочем кластере. В кластер ничего не пишется.
- FreeLens можно перезапускать самостоятельно (`osascript -e 'quit app "Freelens"'`, затем `open -a Freelens`), если пользователь в нём не работает.

## v2: несколько подов (2026-10-28)

- Во вкладке пода есть переключатель охвата Pod / ReplicaSet. ReplicaSet ищется по `ownerReferences` пода, а поды выбираются по его selector, а не по префиксу имени. Если ReplicaSet нет, переключатель не показывается.
- Уровень Deployment и пункт в меню Deployment были сделаны, но убраны 2026-10-28 по решению пользователя: хватает Pod и ReplicaSet. StatefulSet, DaemonSet и Job не поддерживаются.
- Поды перечитываются раз в 5 с. К новым подключается поток, у исчезнувших поток останавливается, а их строки остаются. Подключается до 20 подов (`MAX_PODS`): уже подключённые остаются, новые добавляются по имени, исходный под идёт первым.
- Все поды идут одним списком, буфер общий, 10 000 записей. При открытии берётся по 1000 строк с каждого пода. Записи упорядочены по времени kubelet: живые строки обычно дописываются в конец, а запоздавшая пачка вставляется на своё место.
- Метка пода — часть имени после имени ReplicaSet, например `h99zm`. Цвет зависит от порядка появления пода во вкладке. Чипы подов скрывают и показывают поды. Ушедший под приглушён, а под без выбранного контейнера помечен `—`.
- Контейнер выбирается по имени, общий для всех подов. Список контейнеров показывается, только если их больше одного, включая init-контейнеры. Previous работает только на уровне Pod.
- Смена охвата очищает буфер и заново открывает потоки. Поиск и фильтры сохраняются.
- В `tabs-<clusterId>.json` хранятся под, охват и имя ReplicaSet. Поэтому групповая вкладка восстанавливается, даже если исходного пода уже нет. Записи без охвата или с неизвестным охватом открываются на уровне Pod.
- Охват переключается кнопками, а не выпадающим списком. Кнопки «← Pod» нет.
- У групповой вкладки заголовок `{ } <группа>-*`. API для смены заголовка нет, поэтому родной текст скрывается нулевым размером шрифта, а заголовок рисуется в `::before`.

## v3: шапка D (2026-11-05)

Дизайн выбран из вариантов A–D на холсте «Шапка Structured logs». Переключатель Pod / ReplicaSet, чипы подов и Previous заменены.

- Первая строка: `ns / <ReplicaSet без pod-template-hash>-*`, список подов, контейнер (если их больше одного), уровни, статус. Вторая строка: поиск, `.*`, список логгеров, счётчик. Заголовок не меняется при выборе подов, поэтому шапка не прыгает.
- Выбор подов хранится как «все, кроме» или «только». «Все, кроме» включает новые поды ReplicaSet, «только» их не включает. Вкладка из меню пода открывается в режиме «только этот под».
- Поток открыт только у выбранных подов (до 20). Когда под выключают, его поток закрывается, а строки удаляются из буфера, иначе при повторном включении `tailLines` даст повторы. Строки ушедшего пода остаются.
- Прошлый запуск открывается из списка подов у пода с `restartCount > 0` выбранного контейнера. В плашке время и причина из `lastState.terminated`.
- Уровень OTHER — записи без уровня: строки не JSON и JSON без `level`. Порядок ALL, ERROR, WARN, INFO, DEBUG, TRACE, OTHER. ALL включает все или, если все включены, выключает все. Порогового режима нет.
- Логгеры берутся из буфера, поэтому новый логгер появляется в списке со своей первой строкой. Фильтр не трогает записи без `logger_name`.
- В `tabs-<clusterId>.json` хранится выбор подов (`pods`). Старые записи читаются по `scope`: `replicaset` — все поды, иначе только исходный под.
- Заголовок вкладки: `{ } <под>`, если выбран один другой под, и `{ } <ReplicaSet>-*` для нескольких.

## v4: поиск (2026-11-05)

Образец — Emacs-пакет orderless, через который фильтрует affe. Посимвольный fuzzy (orderless-flex) не взят: без ранжирования он в длинных строках логов совпадает почти со всем.

- Ввод делится по пробелам. Строка видна, если в ней есть каждое слово как подстрока, в любом порядке. Регистр не учитывается всегда, smart case нет. Спецсимволов orderless (`!`, `~`, `=`, `^`) нет.
- Ищется по видимому тексту и по значениям всех полей JSON, включая вложенные, без ключей. Видимый текст: время, метка пода, уровень, короткое имя логгера, message, error, а у строк не JSON — сама строка.
- Совпадения подсвечиваются все. Цвет зависит от номера слова, 4 цвета по кругу. Подсветка есть и в раскрытой строке.
- Если слово не нашлось в видимом тексте, а нашлось в скрытом поле, в строке показывается метка с именем поля, например `mdc.trace_id`.
- `.*` делает весь ввод одним regexp без деления по пробелам. Regexp ищет по тем же полям, совпадение не переходит из поля в поле.
- При смене поиска, уровней, логгеров или подов место в списке сохраняется. Якорь — строка, по которой кликнули последней, если она на экране или скрыта фильтром. Иначе, если автопрокрутка на паузе, якорь — верхняя видимая строка. Якорь остаётся на прежнем расстоянии от верха списка. Если якорь скрыт, берётся ближайшая следующая видимая строка. Кликнутая строка ненадолго подсвечивается. Если после этого список не у самого низа, автопрокрутка встаёт на паузу. Колесо, клавиши прокрутки и скроллбар сбрасывают кликнутый якорь.

## Итоги реализации v1 (2026-10-20)

- Стриминг через `KubeJsonApi.getResponse(..., {signal})` работает, опрос не понадобился. После abort соединение закрывается: при закрытии вкладки, смене контейнера или режима и отключении кластера.
- Установка: симлинк в `~/.freelens/extensions/` создаётся при запущенном FreeLens, тогда он сам линкует пакет в свой `node_modules`. Если ссылку создать при выключенном приложении, расширение обнаружится выключенным.
- Хост отдаёт react-dom как `global.ReactDOM`; в шаблоне указано `global.ReactDom`.
- Previous загружает до 10 000 строк. По умолчанию выбирается первый обычный контейнер, init-контейнеры доступны в списке.
- `stack_trace` в раскрытой строке выводится отдельным блоком и не повторяется в JSON. Copy копирует JSON целиком.
- Пауза автопрокрутки включается только вводом пользователя: колесо вверх, ArrowUp/PageUp/Home или перетаскивание скроллбара. Сбрасывается у самого низа списка или кнопкой.
- После переподключения отбрасываются только повторы строк из последней секунды. `tailLines=10000` ограничивает догрузку после долгого обрыва.
- На полном буфере (10 000 записей) от прихода строк до отрисовки проходит около 80 мс, ввод в поиск — около 40 мс. Виртуализация не нужна.
- 2026-10-21: режим previous у встроенной вкладки проверен на поде без рестартов. И для новой, и для восстановленной вкладки встроенный просмотрщик делает один запрос и больше не опрашивает. Под с прошлым запуском вживую не проверялся: по коду `LogStore.loadMore` новых строк у завершённого контейнера нет, буфер остаётся в пределах 500 строк.
